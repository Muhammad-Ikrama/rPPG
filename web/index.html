Scientific Methodology and Biomedical Integrity

1. Plane-Orthogonal-to-Skin (POS) Algorithm

This system implements the algorithm formulated by Wang et al. (IEEE TBME 2017). Spatial averaging of skin pixels over the forehead and cheeks extracts temporal RGB signals $C(t)$. Within sliding windows of 1.6s duration, temporal normalization $C_n(t) = C(t)/\mu(C)$ isolates pulsatile changes. The signal is projected onto a 2D plane orthogonal to the skin-tone reflection vector, yielding orthogonal components $S_1 = G_n - B_n$ and $S_2 = G_n + B_n - 2R_n$. The dynamic combination $h = S_1 + (\sigma(S_1)/\sigma(S_2)) S_2$ cancels specular motion artifacts.

2. Blood Pressure (ISO 81060-2 Caveats)

Continuous non-contact blood pressure estimation from optical facial video is an active experimental research objective. Peripheral pulse morphology features (Crest Time, PW50, Augmentation Index surrogates) correlate with arterial compliance, but strictly require paired sphygmomanometer calibration per subject. This application never synthesizes default (120/80) values and clearly labels BP as experimental.

3. SpO2 Optical Sensor Limitations

Standard pulse oximetry operates using narrow-band dual emitters (660 nm Red and 940 nm Infrared). Standard consumer webcams and smartphones possess IR-cut filters and broadband ambient lighting, which limits direct optical ratio-of-ratios determination. Uncalibrated SpO2 readings are explicitly designated as experimental research approximations.

4. Biometric Data Privacy and Security

Facial video is sensitive biometric information. All participant data is pseudonymized using randomized Subject IDs. Video files are stored securely with SHA-256 checksum verification and configured with automatic 7-day retention purging. Videos are never shared with commercial third parties.

  • GREEN (Verkruysse 2008): Single-channel optical absorption peak
  • ICA (Poh et al. 2010): Blind source separation decomposition
  • PhysNet (Yu et al. 2019): 3D spatio-temporal deep neural network
